> **FireGuard 360** — отечественная платформа мониторинга пожарной безопасности нового поколения, объединяющая концепцию **архитектурного цифрового двойника здания (3D Digital Twin)**, диспетчеризацию инцидентов в реальном времени, контроль регламентного технического обслуживания (ТО) и сквозной журнал аудита безопасности.

Разработано для конкурса/хакатона 2026.

---

## 🏛️ Ключевые возможности

1. **Интерактивный 3D Digital Twin здания (Three.js):**
   - Полная трехэтажная процедурная модель с детализацией помещений, коридоров, лестничных клеток и лифтовых шахт.
   - Орбитальная камера с плавным зумом, панорамированием и режимом послойной изоляции этажей (Exploded View).
   - Пространственное позиционирование извещателей с цветовой индикацией состояния (`НОРМА`, `ВНИМАНИЕ`, `ТРЕВОГА`, `ОТКЛЮЧЕН`).
   - Пульсирующая подсветка аварийного пожарного отсека в реальном времени.

2. **Уникальная дизайн-система «Industrial Editorial»:**
   - Высококонтрастный инженерный интерфейс: светлый фон `#F7F6F2`, графитовая типографика `#181816`, сдержанные статусные акценты безопасности (оранжевый `#D9531E`, красный `#C92A2A`, изумрудный `#1F8844`).
   - Чистая модульная сетка, технические подписи, отсутствие шаблонных скруглений и «нейросетевых» градиентов.

3. **Управляемая симуляция аварийных сценариев (WebSocket):**
   - Встроенный серверный эмулятор нештатных ситуаций: `Normal Operation`, `Smoke Detection`, `Temperature Warning`, `Fire Alarm`, `Device Offline`.
   - Мгновенная доставка телеметрии по шине WebSocket (`/ws/events`).
   - Защита от дублирования тревог при повторных сигналах из одного отсека.

4. **Диспетчеризация и строгий жизненный цикл инцидентов:**
   - Формирование оперативных карточек инцидентов из тревог ППКП.
   - Машина состояний: `NEW` $\rightarrow$ `ACKNOWLEDGED` $\rightarrow$ `IN_PROGRESS` $\rightarrow$ `RESOLVED` $\rightarrow$ `CLOSED`.
   - **Серверная защита:** перевод инцидента в статус `CLOSED` строго требует внесения технического отчёта о ликвидации и причинах срабатывания.

5. **Регламентное техническое обслуживание (ТО) и калибровка:**
   - Учёт парка извещателей, контроль плановых дат поверки и замены элементов питания.
   - Динамический расчёт просрочки нарядов (`OVERDUE`) на текущий момент времени.

6. **Инженерная аналитика и неизменяемый журнал аудита:**
   - Расчёт ключевого отраслевого показателя **MTTR** (Mean Time to Resolution).
   - Распределение тревог по этажам и типам приборов (ИП 212, ИП 101, газоанализаторы).
   - Единый сквозной журнал аудиторского следа всех действий операторов и автоматики.

## ⚡ Быстрый старт (Quick Start)

### Требования
- Python 3.10+
- Node.js 18+ и npm
- Git

### 1. Серверная часть (Backend)

```bash
# Перейдите в каталог backend
cd backend

# Установите зависимости
pip install -r requirements.txt

# Наполните базу эталонными демо-данными (3 этажа, датчики, пользователи, наряды ТО)
python seed.py --reset

# Запустите сервер FastAPI
python -m uvicorn app.main:app --reload --port 8000
```

- API & Swagger документация: [http://localhost:8000/docs](http://localhost:8000/docs)
- Проверка здоровья системы: [http://localhost:8000/api/health](http://localhost:8000/api/health)

### 2. Клиентская часть (Frontend)

В новом терминале:

```bash
# Перейдите в каталог frontend
cd frontend

# Установите зависимости
npm install

# Запустите dev-сервер Vite
npm run dev
```

- Веб-интерфейс FireGuard 360: [http://localhost:5173](http://localhost:5173)

## 🧭 Навигация по разделам интерфейса

| Код | Раздел | Назначение |
|---|---|---|
| `01` | **Главный пульт (Dashboard)** | Сводка состояния контура, статус здания, счётчики приборов, мини-вид 3D. |

| `04` | **Тревоги и диспетчеризация** | Очередь тревог, подтверждение, перевод инцидентов с отчётами. |
| `05` | **Персонал и доступ** | Учёт дежурных диспетчеров и техников с ролевым разграничением. |
| `06` | **Регламент ТО** | Наряды на поверку, замену батарей, контроль просрочки и фиксация протоколов. |
| `07` | **Аналитика и аудит** | Метрики надёжности (MTTR), диаграммы по отсекам, сквозной журнал безопасности. |
| `00` | **Инженерная дизайн-система** | Эталонная витрина UI-токенов, кнопок, цветовых сигналов и полей ввода. |
